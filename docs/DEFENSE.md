# Підготовка до захисту практичної 4

Flow є асинхронним потоком. Холодна навчальна модель запускається при підписці, а stateIn робить спільний StateFlow. combine перераховує список, коли змінюється база або будь-який фільтр. LazyColumn використовує стабільний id як key. Вибір поста зберігається у selectedId: перехід зі списку фокусує мапу, вибір маркера показує інформацію та дозволяє повернутися до виділеної картки. LocationManager реєструється лише після дозволу; DisposableEffect звільняє слухача. Мапа використовує OpenStreetMap, а її тайли завантажуються мережею.

## Демонстрація

1. Знайди Пост B, зміни тип, мінімальну потужність і порядок сортування.
2. Очисть фільтри, відкрий Пост A на мапі, повернися до вибраної картки.
3. Відмов у доступі до GPS: застосунок має продовжувати показувати навчальні пости.
4. Надай дозвіл і подай тестову координату через Extended Controls емулятора; покажи свою позицію.

## Можливі питання

### Холодний і гарячий потоки?

Холодний flow виконує виробника для кожного колектора. StateFlow вже має поточне значення і ділить стан між підписниками. stateIn пов’язує його зі scope та політикою підписки.

### combine чи zip?

combine видає результат при зміні будь-якого джерела, використовуючи останні значення інших. zip поєднує елементи попарно та чекає відповідні наступні елементи.

### Чому viewModelScope?

Корутини автоматично скасовуються при завершенні ViewModel. Не залишаються безконтрольні фонові задачі, прив’язані до знищеного екрана.

### Чому collectAsStateWithLifecycle?

UI збирає потік відповідно до життєвого циклу, зменшуючи зайву роботу, коли екран не активний.

### Навіщо key у LazyColumn?

Стабільний id зберігає ідентичність картки при фільтрації й перестановці. Індекс не є стабільним ключем при зміні списку.

### GPS-дозвіл гарантує координату?

Ні. Провайдер може бути вимкнений або ще не мати позиції. Потрібні окремі стани: немає дозволу, очікування координати та отримана координата.

### Чому порожня мапа не завжди є помилкою GPS?

Тайли потребують інтернету, а маркери беруться з локальних даних. GPS, тайли й записи — різні джерела; їх треба діагностувати окремо.

## Вправа

Додай сортування за назвою у зворотному порядку. Перевір, що вибраний пост не змінює id після перестановки.
