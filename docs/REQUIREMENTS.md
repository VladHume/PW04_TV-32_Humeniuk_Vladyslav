# Відповідність завданням

## Заняття 13: Асинхронні потоки

combine об’єднує потік Room, пошуковий рядок, тип і порядок. Помилки читання перехоплює catch. StateFlow з WhileSubscribed зменшує фонову роботу без активного екрана.

Реалізація: `MonitorViewModel.filtered`.

## Заняття 14: Динамічний список

LazyColumn будує картки лише для потрібної частини списку. Стабільний ключ id зберігає ідентичність елементів. Для відсутніх даних показується окреме повідомлення.

Реалізація: `RecordsScreen`.

## Заняття 15: Пошук фільтрація сортування

Пошук за назвою не враховує регістр і зайві пробіли. Фільтр обирає тип поста, а сортування впорядковує записи за датою, потужністю дози або потужністю станції.

Реалізація: `MonitorLogic.filter`.

## Заняття 16: GPS і картографія

osmdroid відображає OpenStreetMap і маркери вигаданих постів. LocationManager отримує координати пристрою лише після дозволу. Відмова або вимкнений GPS не заважає переглядати пости. Слухач звільняється при виході з екрана.

Реалізація: `MapScreen`.
