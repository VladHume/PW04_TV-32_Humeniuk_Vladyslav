# Відповідність завданням

## Заняття 13: Асинхронні потоки

combine об’єднує потік Room, пошуковий рядок, тип і порядок. Помилки читання перехоплює catch. StateFlow з WhileSubscribed зменшує фонову роботу без активного екрана. Окремий холодний flow генерує навчальний прогноз; map, filter, retryWhen і stateIn демонструють трансформацію, повтор та спільний гарячий стан.

Реалізація: `MonitorViewModel.filtered`.

## Заняття 14: Динамічний список

LazyColumn будує картки лише для потрібної частини списку. Стабільний ключ id зберігає ідентичність елементів. Для відсутніх даних показується окреме повідомлення. Картка відкриває детальний екран. selectedId пов’язує список із мапою: вибір фокусує об’єкт; із мапи можна повернутися до виділеної картки.

Реалізація: `RecordsScreen`.

## Заняття 15: Пошук фільтрація сортування

Пошук за назвою не враховує регістр і зайві пробіли. Фільтр обирає тип поста, а сортування впорядковує записи за датою, потужністю дози або потужністю станції. Додано сортування за назвою й типом, фільтр мінімальної потужності та статусу навчального порога.

Реалізація: `MonitorLogic.filter`.

## Заняття 16: GPS і картографія

osmdroid відображає OpenStreetMap і маркери вигаданих постів. LocationManager отримує координати пристрою лише після дозволу. Відмова або вимкнений GPS не заважає переглядати пости. Слухач звільняється при виході з екрана. Натискання маркера показує InfoWindow та оновлює вибір; кнопка повертає до відповідної картки. Мапа обмежена власними межами компонента.

Реалізація: `MapScreen`.
